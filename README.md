## 🚀 Ключевые возможности

### 1. FPS Booster (CBSafe.Fps)
Более **64 параметров оптимизации**, распределенных по рендеру, физике, анимациям и сборщику мусора Unity.

* **Готовые пресеты:**
  * **Боевой (Combat):** Отключение вторичных партиклов, осколков от разрушения стен (gibs), следов от пуль/крови (decals), дымки от жары (heat haze), тряски экрана и оверлея урона. Оптимизирует частоту кадров анимаций персонажей на расстоянии (Distant Anim Lod).
  * **Слабый ПК (Potato):** Боевые твики + выключение травы, теней, упрощение камеры, террейна и даунскейл текстур.
  * **Минимум (Minecraft / Super Potato):** Экстремальный прирост кадров: принудительный пиксельный Point Filter текстур, лод построек, агрессивный куллинг (скрытие невидимой геометрии) и ограничение дистанции отрисовки до 400 метров.
  * **Свой (User):** Свободный выбор каждого параметра под свое железо.

* **Физика и память:**
  * `SimplifyDistantAnims` — ограничение тикрейта анимаций игроков дальше 25–28 метров (разгрузка CPU).
  * `AutoMemory` — фоновый периодический сброс мусора (GC) и выгрузка неиспользуемых ассетов из RAM.
  * `DisableCorpsePhysics` & `LimitCorpses` — отключение тяжелых рэгдоллов трупов.
  * `BlockWorkshopSkins` & `UnloadUnusedSkins` — предотвращение микрофризов от подгрузки скинов воркшопа.

---

### 2. Визуальные модули и кастомизация

* **Стеклянный Калаш (Glass AK):**
  * Замена стандартной модели/текстуры штурмовой винтовки на стеклянный полупрозрачный материал.
  * Встроенная плавная RGB-анимация переливания цветов в реальном времени.
  * Выбор статического цвета через выпадающий список в меню.
* **Кастомный Crosshair (CBSafe.Crosshair):**
  * Встроенный прицел с поддержкой геометрических фигур, текстурных оверлеев и динамических превью.
* **Цветовая схема интерфейса (CBSafe.Colors & CBSlotColor):**
  * Настройка цвета маркеров попаданий (Hitmarkers), крови, полосок здоровья/гидратации, меток тиммейтов и рамок слотов быстрого доступа.
* **Кастомизация голографического прицела (CBSafe.Holo):**
  * Замена сетки и цвета точки голографического прицела.
* **Скины на перчатки:**
  * Локальные скины на перчатки без просадок производительности.

---

### 3. Интеграция в интерфейс Rust (OptionsMenu)
Все настройки мода встроены прямо в оригинальное меню настроек игры:
* Вкладка **«ОПТИМИЗАЦИЯ КЛИЕНТА»** с тумблерами и выбором профилей.
* Вкладка **«НАСТРОЙКИ СТЕКЛЯННОГО КАЛАША»** с переключателями RGB и палитрой оттенков.
* Поддержка фильтрации серверов в браузере (Server Browser Filters).

## 🛠️ Сборка проекта

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/yukkayho/CBSafe.git
   ```
2. Откройте проект в **Visual Studio 2022** или **JetBrains Rider**.
3. Убедитесь, что пути к DLL-библиотекам игры в `CBSafe.csproj` соответствуют вашей установке Rust:
   * `Assembly-CSharp.dll`
   * `UnityEngine.CoreModule.dll`
   * `0Harmony.dll`
   * `BepInEx.dll`
4. Выберите конфигурацию **Release | Any CPU** и выполните сборку:
   ```bash
   dotnet build CBSafe.csproj -c Release
   ```
5. Полученный `.dll` файл поместите в папку `BepInEx/plugins/` вашего клиента Rust.
